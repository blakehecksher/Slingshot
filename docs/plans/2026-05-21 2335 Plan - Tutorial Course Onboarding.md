# Plan - Tutorial Course Onboarding
_Created: 2026-05-21 2335_

## Goal

Add a short training course sequence that teaches new players controls, gate order, boost rhythm, trajectory/minimap reading, and basic gravity-assisted turns before the existing racing courses.

## Steps
1. Add tutorial metadata to authored race courses.
2. Add five training courses at the top of the normal course board.
3. Add authored gravity anchors for deterministic tutorial wells.
4. Teach with short non-pausing run tips that stop after the player has a personal best.
5. Mark tutorial courses clearly in the course list while keeping all courses unlocked.
6. Build-check the implementation.

## Notes

- Implemented as normal time-trial courses, not a separate mode.
- Browser/controller playtest is still required to tune gate positions, prompt timing, and anchor pull strength.
